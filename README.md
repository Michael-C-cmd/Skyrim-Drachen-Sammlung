Skyrim-Drachen-Sammlung:

Eine interaktive Sammlung von Drachen aus Skyrim – gefangen, verwaltet und dauerhaft gespeichert. Übungsaufgabe aus meinem JavaScript-Lernplan mit Fokus auf State-Management und Persistenz.



Features:

Drachen fangen, Sammlung verwalten, gefangene Drachen freilassen



State-Management über das Reducer-Pattern – immutable Updates, kein direktes Mutieren


Persistenz über localStorage (Web Storage API)


Responsive UI mit HTML/CSS



Tech Stack:

JavaScript (ES6-Module) · HTML5/CSS3 · localStorage



Starten:

Repo klonen und index.html über einen lokalen Server öffnen (ES-Module erfordern http, kein file://).
